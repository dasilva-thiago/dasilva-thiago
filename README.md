## Featured project · eduAssets

**An open-source equipment management platform for educational institutions.**

eduAssets replaces scattered manual records with a centralized system for school inventory, equipment loans and returns, and incident tracking. It grew from a practical challenge identified in a public-school environment.

- Built API-driven workflows for inventory, loans, returns, and equipment incidents.
- Implemented authentication and role-based access controls.
- Modeled relational data and applied validation and controlled database operations.
- Designed the system around accurate equipment availability and data integrity.
- Includes a read-only guest mode and exports for CSV, Excel, and PDF.

**Project stack:** TypeScript, Vite, CSS custom properties, Node.js, Express 5, Prisma, Zod, PostgreSQL, and Neon. Optional RFID integration uses Python with Raspberry Pi or Arduino Nano. The frontend and API are deployed separately.
